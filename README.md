**JS-JOURNAL** — это легковесная веб-оболочка над официальным API учебного портала **Top Academy**. Проект создан для того, чтобы быстро проверять расписание, домашние задания, оценки и посещаемость прямо на своём ПК или смартфоне без лишних загрузок.
---


## 🛠 Технологический стек:

| Компонент | Технологии |
| :--- | :--- |
| **Backend** | Python 3.10+, FastAPI, Uvicorn, Requests, Tzdata |
| **Frontend** | HTML5, CSS3 (Grid / Flexbox / CSS Variables), Vanilla JavaScript (ES6+) |
| **Интеграция** | REST API Top Academy (`msapi.top-academy.ru/api/v2`) |
