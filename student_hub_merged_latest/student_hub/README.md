# Student Hub — MVP

Личный адаптивный веб-журнал: три основных раздела (расписание, ДЗ, оценки) и профиль. Включены тёмная/светлая темы и PWA-основа для установки на телефон.

## Запуск локально (Python 3.10+)

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload
```

Откройте http://127.0.0.1:8000

Войдите логином и паролем Top Academy. Пароль передаётся только на сервер для входа в официальный API; он не сохраняется. Токен API и сессии хранятся только в памяти процесса, поэтому после перезапуска нужно войти снова.

## Что подключено из предоставленного проекта

- Авторизация через существующий `bot/top_api.py`.
- Расписание на выбранный день.
- Список домашних заданий.
- Профиль и группа.

## Что пока требует проверки

**Оценки:** в предоставленном Telegram-проекте не найден подтверждённый метод API оценок. В интерфейсе уже есть раздел и запрос `/api/grades`, но он намеренно не показывает фальшивые оценки. Чтобы включить реальные оценки (предмет, значение, причина, дата/время, преподаватель) и уведомления о новых оценках, нужно получить подтверждённый маршрут и структуру ответа API из официального журнала/разрешённой документации.

**Отправка файлов ДЗ:** текущий проект содержит чтение списка заданий, но не подтверждённый метод отправки ответа/вложения. Он не имитирует успешную отправку.

## Важная безопасность перед публикацией

Это MVP для локального тестирования, не production-развёртывание:
- Сессии пока находятся в памяти процесса и исчезают при перезапуске.
- Для публичного сервера обязательны HTTPS, `COOKIE_SECURE=1`, ограничение частоты входов, CSRF-защита, надёжное хранилище сессий и защита секретов.
- Не добавляйте `.env`, пароли или токены в архив/репозиторий.
- Ранее раскрытый Telegram bot token нужно отозвать через BotFather и заменить.
- Не пытайтесь обходить защиту сайта; используйте только доступные вашему аккаунту функции и разрешённые API.

## Структура

- `app.py` — FastAPI backend
- `bot/top_api.py` — API-клиент из исходного проекта
- `web/` — интерфейс, адаптивная верстка и PWA
